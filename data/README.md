# Public reference data snapshots

`Facilities_Nov2024.csv` is the COMNAP Antarctic Facilities List (November 2024), retained as a reproducible reference snapshot for the updated research-stations map and importer validation.

Source: https://www.comnap.aq/antarctic-facilities-information

COMNAP states that the facilities list is supplied by member National Antarctic Programs, covers facilities with status Open or Temporarily Closed, and may be used for educational/non-commercial purposes with COMNAP attribution. The listing does not grant permission to use any facility.

PolarOps preserves source values. In particular, the November 2024 CSV contains a positive decimal latitude for `Zhongshan Skiway`; the platform flags/excludes that coordinate from Antarctic map plotting rather than silently inventing a correction.
